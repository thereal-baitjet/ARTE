# Artwork rights and provenance

ARTE distinguishes synthetic studies from real museum works. Synthetic artist identities, images, prices, and commercial listings are labeled demo. Their CSS illustrations do not imply representation, ownership, or real sale availability.

Museum import accepts only a source response that explicitly declares the work public domain and supplies an image. Source object IDs, attribution, source URLs, rights statements, and verification provenance are retained. The Metropolitan Museum of Art publishes qualifying Open Access images under CC0: https://www.metmuseum.org/about-the-met/policies-and-documents/open-access and https://metmuseum.github.io/ . A public API URL alone is not proof of image rights.

Do not import copyrighted contemporary work, scrape commercial inventory, or change a missing rights state into public domain. Unclear and restricted images must remain unpublished or use a metadata-only fallback. Do not infer that museum ownership of an object establishes copyright permission.

Commercial listings need separate source permission, seller/gallery verification, active availability, explicit currency/price provenance, and a recent verification date. Museum records are not purchasable inventory. Current inquiry drafts do not send messages.

See the catalog source manifest and ingestion documentation for the precise imported data and remaining integration limits.
